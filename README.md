# Nano Growth Habit EX - Salepage

Trang Salepage giới thiệu sản phẩm Thực phẩm bảo vệ sức khỏe **Nano Growth Habit EX** - Dinh dưỡng khoa học chuẩn Nhật Bản cho trẻ 6–18 tuổi.

## Tính Năng & Nội Dung
- **100% Nội dung copywriting chuẩn**: Phân tích khoa học tăng trưởng, cơ chế 3 tầng, hệ 5-trong-1, bảng thành phần định lượng 17 hoạt chất, lộ trình 3 giai đoạn.
- **Hình ảnh thật & Giấy phép**: Tích hợp ảnh studio chụp thật sản phẩm, giấy tiếp nhận bản công bố 6660/2022/ĐKSP của Bộ Y Tế, chứng nhận GMP và bằng sáng chế JPA 2009107938.
- **Nhận diện thương hiệu Nhật Bản**: Bảng màu Warm Cream, Cacao đậm và Vàng ánh kim cao cấp.
- **Tương tác**: Responsive di động, thanh sticky bar hành động, form đặt hàng và hệ thống hỏi đáp FAQ accordion.

## Triển Khai (Deploy)
Dự án là trang tĩnh (Static Web), có thể deploy trực tiếp lên Vercel, Netlify hoặc GitHub Pages.
